# 冻结的实现决策

应用版本 0.1.0；理论 4.2.1；软件规格 1.0.0；引擎 0.1.0；JSON schema 1.0.0；Room schema 1；特征映射 psi-1；路径映射 path-projection-1；偏好函数 linear-1。

数值计算使用 Double；金额存储与加减使用 BigDecimal/DECIMAL128，折现因子按规格指数公式计算后显式转十进制。numericEpsilon、paretoEpsilon、rhoEpsilon 均为 1e-9，寿命离散默认 1/12 年。展示舍入不回写输入。

策略级寿命是用户指定主资产自其阶段开始后的剩余寿命，评估窗口统一为 H。其主情感结果取同一阶段；迭代、对齐、rho取用户显式选择的升级对照。不同对照的含义在界面注明，不宣称这就是整条路径的综合效用。

预算默认时点零实际支出；全期累计支出是可选额外约束，不抵扣收入和残值。服务、关键任务、安全、法律及自定义布尔约束不可由高分抵消。

需求按时间节点分段保持。评估时间网格额外包含需求变更、维修和窗口终点，不跳过这些边界。没有已确认个人系数时不能启用乘法或加权和。

主升级对照须显式选择；rho只在价格正增量、明确正相关升级和合法基准的子集计算。此价格规则是工程策略，不是理论新增定理。rho不参加跨类型共同 Pareto。

导入先严格解码和验证所有快照、引用、版本与哈希；正式快照还需与当前版本确定性重算一致。事务中先检测所有 ID 冲突，再插入新数据。此版只支持同版本导入，后续版本必须提供显式迁移。
